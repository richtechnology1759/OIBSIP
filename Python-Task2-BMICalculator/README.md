# BMI Health Tracker

An advanced desktop Body Mass Index (BMI) calculator developed for the Oasis Infobyte Python Programming Internship.

## Project Overview

BMI Health Tracker helps users calculate their Body Mass Index, monitor previous records, and visualize BMI trends through an easy-to-use desktop interface.

---

## Technologies Used

- Python
- Tkinter
- SQLite
- Matplotlib

---

## Features

- Calculate BMI instantly
- Metric and Imperial unit support
- Multi-user record management
- SQLite database storage
- BMI history
- BMI trend chart
- Export records to CSV
- Delete records
- Input validation
- Error handling

---

## Installation

Install the required packages:

```bash
python3 -m pip install -r requirements.txt
```

---

## Run

```bash
python3 bmi_calculator.py
```
