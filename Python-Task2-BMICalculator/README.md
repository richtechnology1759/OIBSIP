# BMI Health Tracker

Advanced BMI calculator for the Oasis Infobyte Python Programming Internship.

## Features
- Tkinter GUI
- Metric and imperial units
- BMI calculation and colour-coded categories
- Multi-user support
- SQLite history storage
- Matplotlib BMI trend chart
- CSV export
- Record deletion
- Input validation and database error handling

## Run
```bash
python3 -m pip install -r requirements.txt
python3 bmi_calculator.py
```
